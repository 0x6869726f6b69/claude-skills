# Style sheet（表記の決定）

校正者と改訂者は、すべてのラウンドでこの決定に従う。ガイドが繰り返すとおり、多くの表記はどちらでも正しく、誤りになるのは混在である（§3, §4.3）。決めたら途中で変えない。変える必要があれば、理由を書いたうえで論文全体に適用する。

- ラウンド1の校正者が「基本設定」「用語」「略語」を埋める。根拠は投稿規定 → 既刊論文 → 原稿の多数派（`scan.md` の集計）の順。
- 改訂者は「変更しない箇所」に、著者の意図で残すと判断した箇所を追記する。以後の校正者はそこを指摘しない。

## 基本設定

| 項目 | 決定 | 根拠 |
|---|---|---|
| 投稿先・規定 | 指定なし | |
| 英語の種類 | US / UK（-ise）/ UK（-ize, Oxford spelling） | |
| 引用方式 | 番号 [1] / 著者年（APA・Harvard・Chicago） | |
| 連続コンマ（A, B, and C） | あり / なし | |
| e.g. / i.e. の後のコンマ | あり / なし | |
| 引用符 | 直接引用は “ ”、強調は ‘ ’（など） | |
| 引用符と句読点 | 内側（US）/ 外側（UK） | |
| 数 | 1〜9 は語・10 以上は数字・単位付きは常に数字・文頭は語（など） | |
| 範囲 | en dash、空白なし（10–20） | |
| 数値と単位 | 空白あり（5 ms）、% は空白なし（5%） | |
| 図表の参照 | Fig. 1 / Figure 1、Table 1（文頭：APA などは Figure、IEEE は Fig.） | |
| キャプションの番号の後 | Table 1. / Table 1: | |
| 見出しの大文字化 | Title Case / Sentence case（階層ごと） | |
| 人称 | we（著者複数）/ I（単著） | |
| data の単複 | data are / data is | |
| 分割不定詞・単数の they | 規定に従う（指定なし → style 扱い） | |
