# レンズ担当ガイド

セグメント検証担当は「範囲ごとに深く」見る。レンズ担当は「論文全体を一つの観点で横断して」見る。セグメントごとに分けると、節をまたぐ問題（Abstract と表の数値の食い違い、記号の意味の途中での変化、主張全体の位置づけ）が見落とされやすいからである。また、LLM のレビューは技術的妥当性に偏り、新規性の評価を見落としやすいことが知られているので、新規性には専用のレンズを置く。

出力形式は `schemas.md` §1（candidates）。加えて `overall_notes` に Overall Feedback 向けの所見を書く。確認項目は `checklists.md` の該当節を使う。

共通の手順：
- 全文（`paper.txt`）を通して読む。数式・表・図に関する指摘は、ページ画像（`pages/page_NNN.png`）で確かめてから書く
- quote は `paper.txt` からの逐語引用。言い換えない
- 1件ごとに一度反証を試み（定義が別の場所にないか等）、残ったものだけ書く
- 上限：15件（L0 は20件）。誤字は1件にまとめる
- 最後に「候補数と、overall_notes の要点」を2〜3行で返す

---

## L1 ストーリーと主張–証拠

論文が「何を主張し、それをどこで示したか」を一本の筋として検証する。

1. Abstract・Introduction・結論から主張を全部抜き出し、C1, C2, … と番号を振る
2. 各主張について、支える証拠（定理・表・図・節）を本文から探す。対応表を作業メモ（`work/` 以下）に残してよい
3. 指摘する：証拠のない主張／証拠より強い主張（overclaim）／Abstract と本文の数値の食い違い／本文で示した範囲を超えた一般化／Limitations で触れるべき前提や失敗例の欠落／問題設定と評価の食い違い（解くと言った問題と実験で解いた問題が違う）
4. 筋の通り方：動機 → 問題設定 → 手法 → 結果 → 結論が一貫しているか。読者が「なぜこの手法か」を理解できるか

`overall_notes`：主張と証拠の対応の総評（どの主張がよく支えられ、どの主張が弱いか）。

## L2 新規性・重要性（文献確認）

1. 論文のサブ分野と、主張されている新規性（何が初めてか、既存研究と何が違うか）を整理する
2. 最近接研究を2〜5本特定する。論文が引用しているものを優先し、必要なら検索で補う
3. **Web 検索が使えるなら**、10回程度まで使って次を確かめる：最近接研究の実在と内容、「初めて」「既存研究はない」という主張の真偽、直近1〜2年の同じ問題への研究。検索結果は公刊・査読済みの研究（論文誌・主要会議）と arXiv を優先する
   - **機密を守る**：検索クエリには一般的な技術用語や既知の関連研究の名前だけを使う。原稿の文章・未公開のタイトル・固有の手法名をそのまま検索に入れない（未発表原稿の内容を外部に送らないため）
4. 指摘する：差分が不明確／最近接研究との比較が欠けている／「初めて」が事実と違う／重要な関連研究の欠落／重要性（誰が、なぜ困るのか）の論証が弱い
5. 外部の研究に言及するときは、著者・年・会議（または URL）まで確認できたものだけを挙げ、`evidence` に確認方法（URL など）を書く。確認できないものは「〜を行う一連の手法」のように系統として述べる。存在しない文献を挙げると、レポート全体の信頼が失われる

`overall_notes`：新規性と重要性の評価（最近接研究との差分を一文で、その差分がどの程度意味のあるものか、検索で確かめたこと）。Web 検索が使えなかった場合はそう明記する。

## L3 整合性・図表・引用

1. **記法**：記号表を作業メモに作り、多重定義・未定義・途中での変更を探す
2. **相互参照**：定理・式・図表・節の番号参照が正しいものを指しているか
3. **節をまたぐ数値**：同じ量（データ数、精度、パラメータ数、計算時間）が節ごとに違っていないか
4. **図表**：ページ画像で、軸ラベル・凡例・単位・読みやすさ、図と本文の説明の一致、同じパネルの重複使用を確認する
5. **参考文献の抜き取り検査**：不自然な文献（著者と題名が合わない、存在が疑わしい、年や会議がおかしい）を最大10件まで検索で確認する。検索が使えなければ、明らかに不完全な書誌情報だけを指摘する
6. **誤字・脱字**：1件の minor（`kind: typo`）にまとめ、explanation に「p.3: …→…」の形で列挙する（最大15箇所）

`overall_notes`：読みやすさ・体裁の総評（任意）。

## L0 統合レンズ（quick モード）

L1・L2・L3 を一人で行う。時間配分は L1 > L2 > L3。L2 の検索は5回程度まで。`overall_notes` には主張と証拠の総評と新規性の評価を書く。
