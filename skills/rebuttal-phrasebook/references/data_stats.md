# フレーズ集の元データと集計の要約

`phrasebook.md` の数字の出どころと、読むときの注意。集計は 2026-11-24 に `scripts/mine_openreview.py analyze` で行った。

## 出典

- データ：Hugging Face の [`Jasonpicky/openreview_raw`](https://huggingface.co/datasets/Jasonpicky/openreview_raw)（`sumukshashidhar-archive/openreview_raw` のミラー）。OpenReview の公開ノートを集めたもの。ライセンスは ODC-By（コンパイルについて）。元の文章の権利は OpenReview と各著者にある。
- 規模：ノート 626,430 件、論文（フォーラム）49,023 件、349 の会議・ワークショップ、2013–2025 年。
- OpenReview の API は、ログインなしの自動取得にボット判定をかけるようになっている（2026-11 時点）。そのため API ではなく、この公開データセットを使った。

## 何を数えたか

| 対象 | 件数 | 定義 |
| --- | --- | --- |
| General Response（GR） | 16,772 | フォーラム直下に置かれた著者のコメントのうち、タイトルが general / global / common / to all reviewers などのもの、または無題で 120 語以上のもの。同じ論文で 1 日以内に続けて投稿された分割版（1/2, 2/2）はつなげた。各論文で最初の 1 本 |
| 査読者ごとの最初の返信 | 124,973 | 査読（official review）に直接ぶら下がる著者の返信のうち、最も早いもの |
| スコアを上げた査読者へのお礼 | 15,011 | 「スコアを上げた」と書いた査読者のコメントへの著者の返信 |
| 個別スレッドでのリマインド | 8,901 | 200 語以下で、議論期間の終わり・返信のお願いに触れる著者の返信 |
| 全員向けのリマインド / お礼 / AC 向けの要約 / 取り下げ | 1,268 / 1,710 / 726 / 499 | フォーラム直下の著者のコメントをタイトルと本文で分類 |

### move（働き）の判定

文に分け、正規表現で 14 種類の働きを判定した（`mine_openreview.py` の `MOVES`）：謝辞、強みの確認、改訂の知らせ、変更点の列挙、追加実験、PDF への参照、共通の懸念、貢献の再確認、誤解への説明、個別返信への案内、結びの願い、追加の質問の歓迎、スコアへの言及、リマインド。1 文が複数の働きを持つこともある。判定は語彙ベースなので取りこぼしと誤判定がある（例：「誤解への説明」は *clarify* を含む文を広く拾う）。

### 句（n-gram）の数え方

小文字化し、査読者 ID・数値・引用番号・引用符内の語句を記号に置き換えてから、3–9 語の n-gram を **論文単位の件数** で数えた（1 論文で何度使っても 1 件）。GR の冒頭・結び・働きごとに、40 件（働きごとは 20 件、個別返信は 120 件）以上の句だけを残した。参考文献の行（arXiv, et al., Proceedings など）は除いた。

### 結果の指標

- **採択**：ICLR 2020–2024 の採否（decision ノート）。ICLR は不採択も含めて全投稿を公開するので、採択・不採択を比べられる。NeurIPS は主に採択論文だけが公開されるため、採択の比較には使っていない。
- **上昇**：その論文（個別返信ではその査読者）の査読者が、コメントで「スコアを上げた・上げる」と書いたか（"raised/increased/updated my score" などの正規表現。直前の否定語 "not", "keep" などは除外）。実際の点数の変化ではなく、査読者の発言にもとづく。データの点数は最終版だけで、rebuttal 前の点数が分からないため。

主な基準値：GR を出した論文の採択 44%（ICLR 2020–2024、n = 4,347）、上昇 59%（ICLR 51%、NeurIPS 72%）。個別返信の上昇 20%（ICLR 18%、NeurIPS 27%）。

| --- | --- | --- | --- |

## 限界

- **すべて相関。** 好意的な査読を受けた論文ほど強みを挙げられ、厳しい査読ほど貢献の再確認や誤解の説明が必要になる。採択との差の多くは、返信の書き方ではなく査読の初期評価で説明できる可能性がある。初期評価のデータが無いため、これを調整できていない。
- 「上昇」は査読者の自己申告で、黙って点数を変えた査読者は数えられない。会議によって書く習慣が違う（NeurIPS で高い）。
- ICLR 2025 は採否がデータに無い。ICLR 2026 以降と NeurIPS 2025 以降は含まれない（NeurIPS 2025 は global rebuttal が廃止されたので、GR の型は個別返信の冒頭に移して使う）。
- 英語の返信だけ。分野は機械学習（ICLR・NeurIPS が大半）に偏る。
- 分類・判定はタイトルと語彙のヒューリスティックで、誤分類がある。

## 著作権について

フレーズ集に載せたのは、多数の論文（少なくとも 20 件、ほとんどは数百件以上）で共通に使われる定型句と、それをもとに書き起こした型だけ。個々の著者の文章は載せていない。`search` コマンドで実例を見る場合も、他の著者の文章をまとめて写さない。

## 作り直し方

```bash
python scripts/mine_openreview.py files                          # ファイル一覧とサイズ（約 0.9 GB）
python scripts/mine_openreview.py download <data_dir>            # ユーザーの許可を得てから
python scripts/mine_openreview.py analyze <data_dir> -o <out_dir> # 約 7 分
```

`<out_dir>/stats.md`（人が読む表）、`stats.json`、`doc_features.pkl`（会議別の再集計用）、`samples.jsonl`（作成者の確認用の短い抜粋。配布しない）ができる。Python 3.9 以上と pandas・pyarrow が必要。
